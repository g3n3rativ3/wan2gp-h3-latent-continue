# Provenance and licenses

This extension includes local edits derived from the MiniMax H3 pipeline in the user-supplied Wan2GP 12.72 and 13.0 source archives. Production code runs the user's installed H3 pipeline, packing and transformer functions. The former copied pipeline and model definitions are no longer shipped.

`packing.py` is an adapted native packing module retained for CPU tests. Its Apache-2.0 SPDX notice is preserved. No code from the related ComfyUI projects is bundled. No model weights are distributed.
